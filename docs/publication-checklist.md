# Checklist before making this repository public

- [ ] Confirm the thesis author and university attribution are accurate.
- [ ] Confirm you have the right to publish any material derived from the thesis under applicable academic policies.
- [ ] Do **not** upload the full thesis PDF without a separate review for personal data and sharing rights.
- [ ] Remove personal/academic identifiers such as student number, contact information and supervisor contact details.
- [ ] Exclude account credentials, hashes, tokens, RTSP URLs, device serial numbers, MAC addresses and identifiable IP/network topology information.
- [ ] Exclude actual surveillance video, screenshots showing private areas, device QR codes and identifiable people.
- [ ] Do not include executable disruption/deauthentication or credential-extraction procedures.
- [ ] Check whether any findings were already disclosed or fixed before describing products as currently vulnerable.
- [ ] Avoid claims of CVEs, universal brand weaknesses, or quantified risk scores without supporting evidence.
- [ ] Review Git history **before** switching visibility: deleted files may still remain in prior commits.

If you later add sanitized images, export new versions with sensitive details permanently removed and manually review each image before committing.
